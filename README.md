# RPS Arena (POC)

เกมเป่ายิงฉุบด้วยการ์ดแบบออนไลน์ 1 ต่อ 1 ตาม **Combat Rules Specification v1.2**
ฉากหลังใช้ three.js ส่วนตัวเกมเป็น UI 2D ตาม `DESIGN.md`

## วิธีรัน

ต้องมี Node.js 18 ขึ้นไป

```bash
npm install
npm start
```

เปิด `http://localhost:3000` คนแรกกด **สร้างห้องใหม่** แล้วส่งรหัส 4 ตัวหรือลิงก์ให้อีกคน เกมเริ่มทันทีเมื่อมีผู้เล่นครบ 2 คน

ถ้าอยากลองคนเดียว เปิด 2 หน้าต่าง (หน้าต่างหนึ่งเป็น Incognito) แล้วเข้าห้องเดียวกัน

## เล่นกับคนอื่น

| วิธี | ใช้เมื่อ | ทำอย่างไร |
|---|---|---|
| Wi-Fi เดียวกัน | อยู่ใกล้กัน | ตอน `npm start` จะแสดงลิงก์ `same Wi-Fi: http://192.168.x.x:3000` ให้อีกคนเปิดลิงก์นั้น |
| Tunnel | เล่นผ่านอินเทอร์เน็ตจากเครื่องคุณ | ติดตั้ง cloudflared (macOS: `brew install cloudflared`) แล้วรัน `cloudflared tunnel --url http://localhost:3000` จะได้ลิงก์ `https://….trycloudflare.com` ส่งให้เพื่อน (ใช้ ngrok แทนได้) |
| Deploy | ให้เปิดได้ตลอด | Render / Railway / Fly.io: Build `npm install`, Start `npm start` เซิร์ฟเวอร์อ่านพอร์ตจาก `PORT` และ WebSocket อยู่ที่ `/ws` บนพอร์ตเดียวกัน |

## วิธีเล่นโดยย่อ

- ทุก Turn จั่ว 1 ใบ แล้วทั้งสองฝ่ายเลือกการ์ดพร้อมกัน (คลิก หรือกดเลข 1-7 แล้ว Enter) มีเวลา 20 วินาที หมดเวลาระบบเลือกให้
- **ชนะ**: เลือก Action (Normal Attack, Charge Mana, Draw Action หรือสกิล) และได้ Hand Bonus ตามการ์ด
- **แพ้**: Angry +1 (คู่ต่อสู้มองไม่เห็น) ใช้ Dodge หรือ Counter ได้เมื่อถูกโจมตี
- **เสมอ**: ทั้งสองฝ่าย +1 Mana
- จบเมื่อ HP หมด หรือมีฝ่ายลงการ์ดใบสุดท้าย

## โครงสร้าง

```
server/
  config.js   ตัวเลข Balance และสกิลทั้งหมด (แก้ไฟล์นี้เพื่อปรับสมดุล)
  engine.js   กติกาเกม ตัดสินผลฝั่งเซิร์ฟเวอร์ ซ่อนข้อมูลที่อีกฝ่ายไม่ควรเห็น
  index.js    HTTP + WebSocket, ห้อง, reconnect, rematch
public/
  index.html
  css/style.css   UI ตาม DESIGN.md
  js/main.js      หน้าจอและ HUD
  js/net.js       WebSocket + reconnect อัตโนมัติ
  js/audio.js     เสียงเอฟเฟกต์และเพลงสังเคราะห์ด้วย Web Audio (ไม่มีไฟล์เสียง)
  js/scene.js     ฉาก three.js และเอฟเฟกต์
test/
  engine.test.js      เล่นสุ่ม 300 เกม ตรวจกติกาและการซ่อนข้อมูล
  server.e2e.test.js  2 client เล่นออนไลน์จนจบ, rematch, reconnect
```

เซิร์ฟเวอร์เป็นผู้ตัดสินทุกอย่าง client ได้เฉพาะข้อมูลที่ตัวเองควรเห็น (การ์ดในมืออีกฝ่ายและ Angry ของอีกฝ่ายไม่ถูกส่งออกไปเลย)

## เพิ่มหรือเปลี่ยนสกิล

สกิลเป็นข้อมูลใน `server/config.js` ตัวอย่าง:

```js
{
  id: 'battlecry', name: 'Battle Cry', tier: 'small', cooldown: 5, cost: 2,
  desc: 'Normal Attack +10% เป็นเวลา 3 Turn',
  effects: [{ type: 'buff', stat: 'normalDamagePct', value: 10, turns: 3 }],
}
```

- `tier` กำหนดว่าป้องกันได้แบบไหน (ตาราง Defense ในสเปก)
- Effect ที่รองรับตอนนี้: `damage`, `heal`, `mana`, `buff` (`normalDamagePct` หรือ `damagePct`)
- Battle Cry มีอยู่แล้วแต่ปิดไว้ (`enabled: false`) เปลี่ยนเป็น `true` เพื่อลอง
- ถ้าต้องการ Effect แบบใหม่ เพิ่ม handler ใน `EFFECTS` ใน `server/engine.js`
- UI สร้างปุ่มสกิลจาก config อัตโนมัติ

## เสียง

เสียงทั้งหมดสร้างสดด้วย Web Audio ใน `public/js/audio.js` (ไม่มีไฟล์เสียง) แต่ละเสียงเป็นสูตรสั้น ๆ ใน `SFX` เปลี่ยนเป็นไฟล์จริงทีละเสียงได้ภายหลัง
- เสียงเริ่มทำงานหลังคลิกครั้งแรก (ข้อจำกัดของเบราว์เซอร์)
- ตั้งระดับเสียงเพลง / เอฟเฟกต์ / ปุ่ม ได้ที่หน้าแรก และมีปุ่มเปิด/ปิดเสียงที่แถบบนระหว่างเล่น
- เสียงของ Angry เล่นให้เจ้าของได้ยินคนเดียว ไม่บอกใบ้คู่ต่อสู้
- ฟังตัวอย่างทุกเสียงได้ที่ `docs/sound-preview.wav` (ลำดับอยู่ใน `docs/sound-preview.txt`)

## ทดสอบ

```bash
npm test
```

ตัวแปรสำหรับทดสอบเร็ว: `RPS_TIMESCALE=0.25` (ย่อเวลาทั้งหมด) และ `RPS_MAXHP=40` (เกมสั้น)

## ข้อจำกัดของ POC

- ห้องเก็บในหน่วยความจำ รีสตาร์ตเซิร์ฟเวอร์แล้วห้องหาย ไม่มีบัญชีผู้ใช้หรือ matchmaking
- หลุดการเชื่อมต่อได้ 45 วินาที (รีเฟรชหน้าแล้วกลับเข้าห้องเดิมได้) เกินนั้นแพ้
- Angry ยังนับย้อนได้จากผลแพ้และการใช้ Defense ที่เปิดเผย (Open Issue ในสเปก)
- เวลาที่อีกฝ่ายใช้ตอบสนองการโจมตีอาจบอกใบ้ได้เล็กน้อยว่ามี Angry พอป้องกันหรือไม่ (ระบบหน่วงเวลาสุ่ม 1.2-2.6 วินาทีเมื่อไม่มีทางเลือกเพื่อลดผลนี้)
- ฟอนต์โหลดจาก Google Fonts (Geist, Inter, Anuphan) ถ้าออฟไลน์จะใช้ฟอนต์ระบบแทน
